# 996 传2 24.08.07 → 传3｜D1 官方文档差异审计

日期：2026-10-14。阶段：**D1 文档审计已开始；D2 实际 PoC 未开始**。本文件只依赖公开官方文档和客户提供的引擎版本截图，未检查客户项目源文件，不构成十天完工保证。

## 一、版本基线及证据可靠性

1. 客户截图显示 `24.08.07`，官方[版本对应表](https://engine-doc.996m2.com/web/#/42/5721)有 `240807 → 3.40.9`（新框架）；因此客户端**应核对3.40.9**，不代表客户实机已证明安装该版本。
2. [M2 Lua官方文档](https://engine-doc.996m2.com/web/#/9/154)记载：2024-08-07起使用LuaJIT，`require` 文件不存在时可能导致加载中断；需纳入Lua/插件扫描，不能只研究TXT。
3. 用户所给传2URL `#/34/3679` 的页面ID3679实际属于[项目39，0323版](https://engine-doc.996m2.com/web/#/39/3679)，项目34是[1208版](https://engine-doc.996m2.com/web/#/34/2064)。两者均不能冒充客户240807引擎完整规范。
4. [M3服务端](https://engine-doc.996m2.com/web/#/27/199)是公开目标资料；[M3 Lua更新说明](https://engine-doc.996m2.com/web/#/46/8174)出现26.0401版本更新记录，但客户**实际准备使用哪一版传3**尚未确定。

**证据等级**：A=传3文档直接规定；B=旧M2/M3公开文档字段差异，不保证适配240807；C=需通过实测才能判断的风险或推论；U=无客户版本/样本证据。

## 三、技术方案约束

只读清点 → 源端文件解析(XLS/CSV/TXT/INI/XML/Lua/资源) → 中间表示IR（带字段类型与来源）→ **按两端具体版本绑定的规则库** → dry-run转换 → 差异/冲突报告 → 目标隔离环境验证。转换器必须能重复运行，未知指令/字段/乱码/数值溢出不可静默跳过；源素材及生产库保持不变。

## 四、D2 PoC 最小客户提供资料（全部只读、脱敏）

| 资料 | 最小规模 | 对方需要配合 |

**D2 Go/No-Go**：先在隔离环境验证一条数据库→脚本→NPC→地图/资源的完整路径，物品唯一ID不丢、中文不乱码、关键属性不截断、错误可复现；无法访问闭源接口或大量专有逻辑无法转换，则重新划定10天目标，不承诺全量游戏无条件上线。
